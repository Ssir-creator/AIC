01 / EMBED

两种嵌入路径，对应两类业务

生成时嵌入适用于已接入的扩散模型；已有图片嵌入适用于企业现成素材。两者的接入条件与算力需求不同。

处理路径当前接入方式运行条件
已有图片嵌入TrustMark / 可见署名TrustMark需安装环境和下载权重
生成时嵌入球形水印 / PRC 参考适配器需配置对应代码、模型、密钥与CUDA环境
本地流程测试内置轻量水印无需GPU，用于演示登记与核验流程
02 / TRACE

关联的是登记来源，不是对所有图片判真伪

检测支持的水印后，尝试匹配本服务的登记记录。未检出不代表非AI生成；匹配记录不证明内容真实、版权归属或使用授权。PRC当前适配器仅提供水印检测，不能唯一定位单张图片任务。

03 / CONTROL

企业记录私有，公开信息由登记方选择

工作空间分别存储图片与记录；公开核验只显示选择公开的平台、内容名称、编号和登记时间。提示词、邮箱、内部业务编号及密钥不公开。

开发者文档

接入你的业务，
保留你的工作方式。

使用API密钥提交图片任务，通过任务编号获取结果。网站与API共用同一份来源记录。

快速开始管理API密钥 ↗模型适配范围 ↗

1. 创建工作空间与应用密钥

进入企业控制台，在“开发者中心”创建应用。完整密钥仅在创建时显示一次，请保存在服务端。

2. 提交已有图片嵌入任务

将图片编码为Data URL，指定方法和业务任务编号。正式图片嵌入使用 trustmark；无GPU测试可以使用 builtin。

HTTP · 异步任务
3. 查询处理结果
使用返回的 job_id 请求 GET /api/jobs/{job_id}。状态为 done 时返回图片路径与内容编号；为 error 时返回错误说明。下载图片也需要身份认证。
4. 检测与查询来源
POST /api/trace 检索本工作空间的登记内容；公开核验接口 POST /api/public/trace 仅返回允许公开的来源字段。两者请求体均为 {"image":"data:image/png;base64,..."}。
当前服务为可运行的本地企业原型，支持工作空间隔离、密钥撤销与调用日志。API密钥当前拥有所在空间的完整接口权限；模型推理需另配运行环境，未启用付费计费和生产服务承诺。
