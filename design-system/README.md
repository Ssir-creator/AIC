# 图溯界面设计规范

依据 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的 design-system 检索（B2B developer service editorial minimal）和可访问性规则制定。

- 信息结构：产品官网 / 无需登录的公开核验 / 需登录的企业控制台。
- 风格：编辑式排版、轻量工具界面；内容和操作优先。避免紫色渐变、发光、无意义大图标、浮动卡片堆叠、虚构客户标志与指标。
- 配色：强调蓝 #2456C4、正文 #18212F、次级文字 #586273、边界 #DDE1E7、页面 #F7F8FA；状态颜色始终配文字。
- 字体：中文系统无衬线；数字与接口使用等宽字体。正文 15–16px，辅助文字不小于12px。中文标题使用字重和留白，不使用西文展示字体堆叠。
- 圆角：表单/按钮6px，面板8px；无大面积阴影。使用细边框和分隔线。
- 可访问性：可见焦点，显式label，44px操作目标；原生按钮/对话框；弹窗关闭回到触发控件；状态使用aria-live；尊重减少动态效果设置。
- 移动端：375、768、1024、1440宽度检查；表格独立滚动；侧栏折为可展开导航。
- 数据：不伪造客户、调用数、余额、付款与模型执行结果。密钥、提示词、内部任务不出现在公开核验中。
- 业务：生成时嵌入与已有图片嵌入分开；内置水印为本地测试方法，放在高级选项。报价为合作方案而非已验证单价。
