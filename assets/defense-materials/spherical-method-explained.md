# 球形水印｜方法与技术框架

一、先用一句话理解这篇论文

球形水印不是在生成完的图片上叠加图案，而是把身份消息编码成扩散模型的初始噪声，再由模型生成图片。核验时，通过图像反演估计初始噪声，逆向恢复消息。论文为Spherical Watermark: Encryption-Free, Lossless Watermarking for Diffusion Models，原文标注ICLR 2026。

二、完整技术框架

离线：构建固定签名K=(T,C)，保存可逆二进制变换T和正交旋转C。
生成：消息m → 重复N次并拼接随机填充r → 二进制可逆混合T → 0/1转为±1 → 单位球面归一化 → 正交旋转C → 随机半径缩放 → 扩散采样 → VAE解码得到图像。
恢复：待查图像 → VAE编码 → 空提示词扩散反演 → 逆旋转与方向/符号恢复 → 二进制逆变换 → N组重复消息多数投票 → 恢复m。
项目业务层再将m关联到登记记录；这一步不是论文球面映射本身。

三、模块1：重复编码与随机填充（原文第4页）

消息m是需要携带的二进制身份信息。将其重复N次，为后续纠错提供冗余；每次调用重新采样随机填充位r。拼接得到x=[m,m,...,m,r]，总维度l_x=N*l_m+l_r。重复消息会产生相关性，因此不能直接把重复后的比特当作独立高斯噪声。
论文默认l_m=512、N=31、l_r=512，所以总维度为31*512+512=16384，对应Stable Diffusion的4*64*64潜在噪声。这里512 bit是消息长度，重复31次并没有把有效身份容量变成15872 bit。

四、模块2：二进制可逆混合（原文第4—5页）

论文构造T=[[I,R],[0,I]]，在二元域F2中计算b=T*x。加法是异或，不是普通实数相加。等价地，上半部分为重复消息 XOR (R*r)，下半部分保留随机填充r。
由于异或同一项两次会抵消，该构造满足T的逆仍为T。因此，恢复填充位后即可逆向解除混合。
R是稀疏二进制矩阵。论文让同一消息比特的N个副本与互不重叠的随机填充子集混合。参数s控制每个副本混合多少个填充位；s增大可改善随机性，但也可能放大恢复错误。这是分布性质与纠错能力之间的取舍。

五、模块3：球面映射（原文第5—6页）

第一步，v=2b-1，将0/1转成-1/+1。
第二步，u=v/||v||，将长度固定为1，使编码主要体现在高维向量的方向上。这里的球面是高维单位球面，PPT上的三维球只是示意。
第三步，u_rot=C*u。C为正交矩阵，由高斯随机矩阵做QR分解得到。正交变换保持长度，逆变换是转置C^T，并将原本按坐标组织的编码分散到多个方向。
第四步，采样半径a，使a^2服从自由度l_x的卡方分布，构造z_w=a*u_rot。注意：服从卡方分布的是半径的平方；半径本身服从卡分布。
这一步依据高斯向量的极坐标分解：理想情况下，独立的均匀球面方向与卡分布半径组合，可得到标准多元高斯。仅做归一化并不能得到完整的高斯噪声。

六、模块4：扩散生成与反演恢复（原文第5页）

生成时，将z_w作为初始噪声，与文本提示一同交给预训练扩散模型，逐步去噪后通过VAE解码得到图片，不需要重新训练整套生成模型。
核验时，先用VAE编码图片，再用空提示词执行扩散反演，估计初始噪声。反演是近似过程，压缩、裁剪、VAE误差和采样误差都可能影响恢复。
随后应用C^T逆旋转，恢复方向与比特判决，逆向执行T，得到N份消息副本。对同一位做多数投票得到最终消息；N取奇数可避免平票。它是重复码的纠错，不意味着可以抵抗任意攻击。

七、“无加密”“无损”应如何理解

无加密：不依赖为每张图片执行流加密并保存一套独立加密密钥，但论文明确要求固定签名K=(T,C)在运行期保持秘密。因此，无加密不等于无秘密参数，也不等于泄露后仍安全。
无损：目标是尽量保持原有生成分布和视觉质量，不是保证带水印与不带水印图片逐像素相同，也不是把受损图片恢复为原图。
理论边界：论文建立三阶独立性和球面3-design等性质，并通过分布测试与图像实验提供证据。第5节明确说明高阶矩可能偏离真实先验；不能将三阶矩一致或边缘曲线接近，直接表述为对所有攻击者严格不可区分。

八、论文实验设置与计时口径

原论文第4.1节：SD v1.5和v2.1；512*512图像；4*64*64潜变量；50步DPM-Solver++生成，guidance scale=7.5；50步DDIM反演，guidance scale=1.0，空提示词；N=31、l_m=512、l_r=512、s=1；实验平台为4张RTX 4090。上述是作者设置，不自动等于团队复现设置。
原文效率实验平均100次，只统计“水印消息与潜在噪声之间的变换”，明确排除扩散采样与反演。因此，毫秒级编码/解码耗时不能称为整张图片生成或完整来源核验耗时。团队表格仍应以实际测量代码核对计时范围。

九、与图溯的对应及答辩表达

论文提供：生成端消息嵌入、传播后消息恢复及相关分布和鲁棒性研究。
图溯的应用层负责：匿名身份登记、作品与业务关联、公开范围、查询报告、API接入及账户隔离。算法恢复消息，并不自动证明版权、授权或画面真实，也不能重建全部转发路径。
答辩可说：我们以球形水印为技术基础，将作品身份映射为与扩散模型相适配的初始噪声，生成携带标识的图像；传播后通过反演、逆变换和多数投票恢复身份消息，再与业务登记关联，形成来源核验服务。

十、与你前面两个问题的直接联系

为什么接近高斯分布有助于保持质量？因为它减少水印对模型训练先验的偏离，目标是保持原有质量，而不是保证每张图片都好看。
密钥泄露怎么办？固定签名T、C仍应保护；泄露后可能影响来源标识可信度，需要轮换签名并对旧版本结果复核。版本管理和撤销不是原论文本身就提供的完整业务机制，也不能用新签名自动修改已经传播的旧图片。
