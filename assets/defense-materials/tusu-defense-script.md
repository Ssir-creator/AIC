# 图溯｜8分钟比赛答辩稿

第1页｜封面 〔建议10秒〕

各位评委老师好，我们的作品是“图溯”——面向数字图像可信传播的来源认证与溯源方案。
我们的目标是：生成时留下身份，传播后找回来源。

第2页｜现实背景·事件引入 〔建议30秒〕

2023年，一张所谓“五角大楼附近爆炸”的虚假图片在网络传播，一度引发市场波动。
事后核查发现，图中存在建筑外观不符、灯柱和围栏异常等造假痕迹。但随着生成技术进步，仅凭肉眼寻找破绽会越来越困难。
因此，我们希望为图片增加一种核验依据：在生成时嵌入身份标识，让传播后的图片仍有可查的来源。这就是图溯的切入点。

第3页｜政策背景 〔建议10秒〕

国家持续推进内容标识与安全治理，身份认证、来源追溯和知识产权保护成为数字内容可信流转的重要支撑。

第4页｜市场调研与用户需求 〔建议35秒〕

我们重点关注两类用户：一类是AI图像生成平台，另一类是设计、营销等内容生产企业。
平台需要关联图像与生成任务，企业需要在交付后核对素材来源，使用者则希望上传图片就能查询，不必提前知道它经过哪些转发和处理。
因此，我们将需求转化为三个功能目标：生成时可标识，交付后可管理，再次收到图片时可核验。

第5页｜现有技术的三大瓶颈 〔建议25秒〕

要实现这些目标，水印技术面临三个取舍。
第一是图像质量。标识应尽量不影响图片观感，也不明显干扰原有生成过程。
第二是传播鲁棒性。图片经过压缩、缩放或编辑后，身份信息仍应尽可能恢复。
第三是部署成本。企业希望接入已有模型和业务流程，减少额外训练与集成负担。
我们需要在质量、可恢复性与成本之间取得平衡。

第6页｜球形水印的技术选择 〔建议15秒〕

针对这三个问题，我们选择球形水印作为核心研究方法：通过球面编码兼顾分布与恢复，并与预训练扩散模型结合，减少额外训练需求。
在此基础上，项目进一步完成来源登记、业务关联和核验服务设计，让算法能力能够进入实际使用流程。

第7页｜图像质量：球面约束 〔建议30秒〕

首先解释为什么采用球形水印。
扩散模型通常从随机噪声开始生成图像，如果嵌入消息明显改变噪声分布，就可能影响生成质量。
球形水印利用球面方向承载编码信息，再结合旋转和半径采样构造输入，使其尽量符合模型预期的噪声分布。
右侧图展示了坐标分布和径向分布的比较。这里的关键是分布兼容；单独做归一化，并不等于已经保持完整的高斯分布。

第8页｜解决检测恢复问题 〔建议30秒〕

第二个重点，是图片传播之后能否恢复身份信息。
我们进行了团队复现，比较不同图像处理条件下的水印恢复表现。以表中的JPEG质量参数50为例，比特恢复准确率为95.12%。
这说明，在本次测试条件下，压缩后的图片仍保留了较好的消息恢复能力。
但恢复消息只是第一步。还需要将消息与有效登记关联，才能进一步形成来源查询结果。因此，我们分别关注比特恢复和完整来源匹配。

第9页｜解决部署复杂问题 〔建议25秒〕

第三个重点是部署成本。
球形水印可以结合预训练扩散模型，无需为水印重新训练整个生成模型。
我们对球形水印与PRC进行了复现比较，表中展示了本次实验设置下的处理开销差异。
这些环节耗时不直接等于完整生成或核验耗时。因此，在应用中，我们通过异步任务衔接网页与模型，让用户能够提交任务、查看状态并获取结果。

第10页｜技术路线：生成端 〔建议40秒〕

下面看完整的生成过程。
首先，为作品建立匿名标识，并关联业务编号等登记信息；接着，经过编码、可逆混合和球面映射，构造与扩散模型相适配的初始噪声；最后，由预训练模型生成带有水印身份信息的图像。
这样，即使文件名被修改，原始网页说明没有一起转发，系统仍有机会从图像中恢复身份线索。
图片中承载匿名标识，详细业务资料保留在登记端，也便于控制信息公开范围。

第11页｜技术路线：核验端 〔建议40秒〕

核验端对应一条反向链路。
用户上传手中的图片，系统通过潜在编码和扩散反演估计生成噪声，再恢复水印消息，并与来源登记记录关联，返回允许公开的信息。
用户不需要事先说明图片经历过什么压缩或转发操作。对未匹配、恢复不足或材料异常的情况，系统给出提示，供人工进一步核查。
这里核验的是来源线索。水印匹配并不能单独证明画面内容真实，也不能自动确认版权归属；这也是系统设置核查边界的原因。

第12页｜功能原型与验证 〔建议60秒〕

围绕这条链路，我们完成了可运行原型，将操作组织为添加标识、管理来源和检测核验三个环节。
以一张营销配图为例：创作者处理图片并登记信息，交付后统一管理记录；再次收到图片的人，上传即可查询允许公开的来源。
系统还提供批量处理、API密钥管理和调用日志。当前网页演示采用内置轻量水印验证业务闭环，球形模型通过独立环境接入。
在工程验证方面，22项自动化测试已通过，覆盖图片流程、工作空间隔离、公开信息脱敏及失败处理等行为。

第13页｜技术成果转化与应用落地 〔建议60秒〕

落地方面，我们优先面向有持续图像生产需求的企业，把来源标识接入素材生成和交付流程。
例如，营销企业交付配图时同步完成登记；图片再次出现时，编辑可以快速核对来源，再决定是否进一步审核授权材料。
对生成平台提供API接入，对内容团队提供网页操作，后续按调用量、年度订阅及私有化部署探索收费。
我们希望形成的差异化，是让水印恢复、业务关联和后续核查衔接成可使用的服务。

第14页｜发展规划 〔建议20秒〕

下一步分三个阶段推进：先完善模型接入与测试，选择具体业务开展小范围试用；再根据核验效果、使用反馈和处理成本优化服务；最后逐步拓展模型与应用领域。
重点跟踪来源匹配表现、误报、处理时延，以及用户完成核验所需的操作成本。

第15页｜社会价值 〔建议15秒〕

图溯希望为三类工作提供帮助：辅助识别内容来源，支持创作者权益核对，并为平台审核提供线索。
通过技术与业务流程结合，让数字内容的使用多一份依据，也让异常情况更便于核查。

第16页｜结束页 〔建议15秒〕

我们希望通过图溯，让图像的身份线索跟得上内容的传播。
让每一张图，有源可溯。
