四、Linux可执行程序启动

1. 将runtime-linux.zip完整解压到拥有写权限的本地目录，保留tusu、assets和model_worker.py等相对位置。

cd 解压后的目录
bash start.sh

2. 保持终端运行，在同一台机器浏览器打开http://127.0.0.1:8765。首次访问点击进入工作空间并注册，无预置管理员账号。

3. 停止时在启动终端按Ctrl+C。重新执行start.sh即可恢复访问；data中保留账户、图片及来源记录。不要在运行中删除数据目录。

4. 端口占用时执行以下命令，并在浏览器打开对应端口：

./tusu --host 127.0.0.1 --port 8766

五、Windows/macOS与云端方式

Windows：预装Python 3.11+后，解压source-code.zip并双击start.bat，首次安装Pillow、NumPy需联网。macOS/Linux可执行bash start.sh；其他系统本轮未实际启动验证。

Codespaces：在运行包目录执行./tusu --host 0.0.0.0 --port 8765，随后在端口面板找到8765，选择打开浏览器。127.0.0.1是云机器内部地址，不是可直接分享的互联网网址。

九、故障排查与运行限制

网页打不开：先检查终端是否持续运行，再检查/health、端口及转发地址。地址不可沿用已停止或重建的旧Codespaces链接。

提示GLIBC版本缺失、Exec format error或权限问题：核对Linux架构与系统版本，执行chmod +x tusu；不兼容时使用Python源码方式。

模型未配置或缺权重：只影响对应模型，不影响本地演示。处理失败不得按成功图展示；未检出不能据此断定非AI生成。

本原型同时只执行一个图片任务；任务状态在内存中，重启后丢失，账户和来源记录保存在data中。无真实支付、账单、企业成员角色或生产SLA。建议本地评审演示，不将单进程原型直接开放为公网生产服务。
