# 图溯 · AI图像水印与可信溯源服务

面向AI图像生成平台和数字内容生产企业的可运行原型。将图片水印、业务任务关联、来源核验与企业接入组织为一条完整工作流。

## 界面与入口

- `/#home`：产品介绍与服务对象。
- `/#capabilities`：嵌入路径、模型条件和核验边界。
- `/#verify`：无需登录的公开核验，仅显示登记方允许公开的字段。
- `/#docs`：API快速开始与适用范围。
- `/#plans`：服务方案与合作需求登记；不提供在线购买或支付。
- `/#console`：企业注册/登录，进入隔离的工作空间。
  - 使用概览：实际登记数和近期调用统计。
  - 水印任务：已有图片嵌入、生成式水印、单张和批量处理。
  - 内容与来源记录：搜索、来源详情、业务编号、公开范围与检测历史。
  - 检测与报告：单张/批量检测、报告下载和传播效果测试。
  - 开发者中心：创建/撤销API密钥、接入测试、实际调用日志。
  - 企业设置：名称与访问规则。

采用原生HTML/CSS/JavaScript和Python标准库HTTP服务，不需要前端构建。设计规范见 [design-system/README.md](design-system/README.md)，参考 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)。

## 本地运行

```bash
python -m pip install -r requirements.txt
python app.py --host 0.0.0.0 --port 8765
```

本机打开 `http://127.0.0.1:8765`。Codespaces使用“端口”面板中的8765端口打开浏览器。更新代码后重启服务：

```bash
bash .devcontainer/start-preview.sh --restart
```

`.devcontainer/devcontainer.json`保留依赖安装、测试与自动预览启动配置。`render.yaml`保留Render部署配置。

## 体验完整流程

1. 创建企业工作空间，打开“水印任务”。
2. 上传PNG/JPG，填写内容名称、业务编号和公开范围。
3. 有TrustMark环境时使用隐形水印；没有模型环境时，展开“本地流程测试”，勾选内置轻量水印。可见署名必须填写自定义署名，不支持隐形水印检测。
4. 执行处理，查看前后对照并下载交付图片。
5. 在“内容与来源记录”查看业务关联与公开字段。
6. 上传交付图片到“检测与报告”或公开核验。非公开记录只提示已匹配，不显示内部信息。
7. 在开发者中心创建密钥，复制接入文档请求进行实际API调用。

## 模型与边界

- 内置轻量水印可在CPU本地完成嵌入、登记与检测。短标识仅作演示和来源线索，不构成工业级安全保证。
- TrustMark需环境及权重；检测到软件包或配置只代表环境存在，不代表权重已下载或实际推理成功。
- 球形水印与PRC参考适配器需要按`config.example.json`配置已有代码、模型、可信本地密钥文件及CUDA环境。
- 球形适配器目前只按完整恢复消息关联记录，不虚构检测阈值；PRC当前适配器不提供唯一图片消息，因此检出不代表能定位某张图的生成任务。
- Tiny-SD是生成后嵌入路径，首次需从Hugging Face下载`segmind/tiny-sd`；未在本次无GPU/离线权重环境验证实际模型推理。
- 未检出不代表非AI生成；记录匹配不证明版权、授权或事实真实性。

## 数据与接口

账户、会话摘要、密钥摘要、请求日志和合作申请保存在`data/_service/service.sqlite`；密码使用scrypt派生值，不保存明文。工作空间图片和来源记录保存在`data/workspaces/<workspace-id>/`。完整API密钥仅在创建时返回一次，可以撤销。

原有`data/`根目录文件不会被删除，也不会自动分配给新注册账户；旧记录默认不公开。匿名核验临时图片在正常检测结束后删除，不写入企业检测历史。处理过程中断造成的临时文件需由部署方定期清理。

企业HTTP接口需要会话cookie或`Authorization: Bearer <key>`。`POST /api/jobs`提交watermark/generate/trace任务；`GET /api/jobs/{id}`轮询。图片下载同样需要认证。公开页面通过`POST /api/public/jobs`异步核验并通过`GET /api/public/jobs/{id}`轮询；结果仅保留公开字段。还保留`POST /api/public/trace`供同步接入测试。

本原型为单进程、单个同时执行的图片任务设计。异步任务状态暂存在内存，服务重启后失效；账户与来源记录仍持久保存。当前每个账户对应单管理员空间，不提供企业身份认证、邀请成员、细分角色、硬性额度、真实账单、在线支付或邮件通知。API密钥拥有所属空间完整权限。合作申请只在本服务中保存，可下载留存，没有对外发送通知。

近期统计最多覆盖500条实际请求日志，不伪造营业额、付费客户或模型成绩。图片记录仍采用JSON；多进程生产部署应引入统一数据库、任务队列、速率限制、TLS及备份。该原型不应直接作为开放公网的生产身份服务。

## 验证

```bash
python -m unittest -v
```

测试覆盖原有图片处理流程，以及账户/会话、工作空间隔离、图片访问控制、密钥撤销、公开字段脱敏、异步任务归属、来源关联和失败不登记等行为。模型测试夹具只验证调用协议，不代表论文模型的真实推理效果。
