# 图溯 · 参考设计双版初稿

按所提供《微氢芯锋》参考稿的19页节奏制作：深黑绿、青绿科技边框、金色结论、透视网格底座。

两版均采用球形水印论文原始框架与实验图，不使用AI生成场景插画。论文出处及方法边界放在演讲者备注。

以数字图像可信传播为背景，展开来源认证、溯源与权益线索，电商作为一个验证场景。
