# 测试证据与落地执行材料

## 本次受控试验

2026-10-15，实际执行当前原型的 `watermark` 和 `trace` 处理函数。24张640×640程序自绘设计样张、3类布局；另24张独立无水印样张。每张正样本分别执行原图、JPEG90、JPEG50、缩放50%、中心保留宽高70%的裁剪，共120次正样本核验和24次负样本核验。

**方法为内置轻量水印，不是球形水印或TrustMark。** 这是单机受控软件试验，不是商户试点、用户调研、真实平台转发或模型GPU评测。小样本未出现错误关联，不能据此宣称总体零误检。
