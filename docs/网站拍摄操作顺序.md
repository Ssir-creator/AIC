# 网站实际拍摄操作顺序

这是操作提醒，不是代拍视频。参赛者本人操作、解释当前网站功能；账号通知、学校和指导教师信息不要进入画面。

1. 上传本人演奏短录音，或打开私有春雨案例；明确这是AI音符初稿。
2. 在听音校对页点一个音符，播放原音，演示半速和选中音符循环。
3. 对实际核对确认的识别问题修改音名或起止时间，必要时补音、删除和撤销。没有确认的修改只能说明是操作演示。
4. 参考对照页导入已确认MIDI；已有春雨八音提纲仍待确认。自动定位后解释差异来源，不能当作演奏评分。
5. 乐谱页填真实BPM/拍号/起拍位置，生成预览；原曲设置未确认时说明是草稿设置。对照原始与当前结果，导出MusicXML、MIDI和校对记录。
6. 说明固定十六分网格、复杂技法和自由节奏限制，并展示实际已经完成的验证。

目前浏览器预览可用；实际MuseScore导入、Windows设备和独立琵琶效果仍需真实验证。
