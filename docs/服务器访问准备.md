# 服务器访问准备

目标是让参赛者在自己的浏览器操作完整版。当前云环境没有对外预览入口；部署到自己的服务器不会让聊天界面自动获得内嵌预览能力。

完整版入口用私有试用包，不用网页浏览预览包。解压后进入AIC目录，系统需有Python3.12和ffmpeg。

Linux服务器准备好前提后运行：

```bash
python3.12 scripts/run_trial.py
```

Windows本机准备好前提后，在PowerShell运行：

```powershell
py -3.12 scripts/run_trial.py
```

该命令安装锁定依赖、导入私有春雨案例并启动应用。终端保持运行；安装错误保留原始提示，不忽略失败。仅检查已装环境可以加--check。

有SSH的Linux服务器可通过端口转发访问，不需要域名或把应用端口开放给所有人。在自己Windows的PowerShell另开窗口，使用实际登录信息替换占位项：

```powershell
ssh -L 8765:127.0.0.1:8765 用户名@服务器地址
```

保持该窗口连接，然后在自己的浏览器地址栏输入本机8765端口地址。此处的本机地址属于用户Windows电脑，不是Codex云端网址。

如果只能用网页控制台，需要根据服务器系统、已有反向代理和访问入口配置具体网址。当前应用是可信单人服务，含本人录音与项目操作；公开网址需配置访问控制和HTTPS。先确认实际服务器入口，再生成对应配置，避免凭空给出不可访问的地址。

只需提供系统名称、登录方式、是否已有网址或域名。密码和私钥不要发送到聊天中。
