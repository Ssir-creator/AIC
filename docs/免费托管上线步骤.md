# 免费托管上线步骤 / Render Docker方案

此方案承载Python完整版，不是GitHub Pages浏览版。Render需要由参赛者本人注册并授权GitHub仓库；当前没有取得Render账号，尚未上线。平台免费计划、地区和资源条件以创建页面实际显示为准；如果平台要求升级付费，先停止，不自动接受费用。

配置在render.yaml：Docker运行、free计划、一个工作进程、健康检查、自动部署、登录名aic和平台生成的访问密码。应用适配平台PORT环境变量。运行镜像不包括本人录音、演示数据或密钥。

免费实例可能休眠，冷启动较慢；其临时文件存储在实例重启或重新部署时可能丢失。网页会提示导出校对记录。若资源不足导致推理失败，保留失败记录，不能承诺免费实例稳定适合正式答辩。

代码推送到部署分支后：进入https://dashboard.render.com/，使用GitHub登录；New选择Blueprint，选择Ssir-creator/AIC仓库和已实际发布的部署分支，检查费用为free后创建。平台自动生成的AIC_ACCESS_PASSWORD在其Environment页面查看；登录名aic。密码不要贴到聊天中。

等待服务状态Live，再使用平台实际分配的onrender.com网址。不能在服务创建前编造网址。上线检查包括：无登录访问项目被拒绝、登录后真实短录音上传/编辑/预览/导出，以及冷启动表现。只有检查完成后才能称为已经上线。

部署分支变化才触发该服务更新；只修改本地工作区或其他分支不会自动更新。需要确认autoDeploy配置确实被平台接受。离线完整版继续保留。

## 当前本地部署验证

Docker镜像已构建，实际容器在512MB内存/1CPU限制下完成春雨30秒77音符识别、原始保留与编辑、三类导出、删除及访问保护检查，当前检查通过；它不是Render平台已上线或音乐效果证明。容器下载依赖遇到当前云网络代理证书时，通过BuildKit只读挂载本机已有受信CA证书集供pip验证，未关闭TLS校验，证书集未放入源码或作为运行密钥保存。Render构建使用其正常网络证书环境，仍需平台实测。
