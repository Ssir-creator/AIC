# 谱易改阶段评测报告

日期：2026年10月11日。作品方向：AI+软件创新。此报告是开发阶段记录，不能替代官方模板中的完整技术方案和最终参赛材料。

## 已完成的真实数据验证

官方GuitarSet v1.1.0的360段麦克风音频与360份JAMS标注已下载，两个归档通过发布页公布的MD5校验。数据许可为CC BY 4.0，署名见third_party/GUITARSET_ATTRIBUTION.md；代码仓库的MIT不能替代音频与标注许可。

在推理前用随机种子2026固定12段，覆盖独奏和伴奏模式。12段全部通过标注与音频配对检查，推理全部完成，没有失败或拒绝。总音频时长391.968秒，参考音符2263个，预测音符2223个。

评测协议：音高容差50音分，起音容差50毫秒；加入结束时间时，容差取50毫秒与参考音符时长20%中的较大者。指标为逐段计算后宏平均的音符级F1，不是“准确率百分比”。

| 项目 | 12段诊断样本 |
| --- | --- |
| 音高与起音F1宏平均 | 0.7975 |
| 音高、起音与结束时间F1宏平均 | 0.5660 |
| 成功 / 失败 / 标注拒绝 | 12 / 0 / 0 |
| 合计推理耗时 | 7.628秒 |

时间包含首段模型加载，不含音频解码、上传传输和交互。属于当前Linux/CPU机器的观测，不代表所有Windows电脑或服务器速度。

Basic Pitch上游含GuitarSet训练流水线，已发布权重的具体划分尚未核实。本报告不能称为对完全未见数据的泛化测试，更不能推广为琵琶识别精度。

## 实际错误与产品决策

起音与音高匹配1699对；按该协议，524个预测音符未匹配，564个参考音符未匹配。在已匹配音符中，625对结束时间偏差超出容差，其中270对偏早、355对偏晚。因此不能统一拉长音符。

原型的短音符/弱音符提示标记610个音符，其中198个未匹配；提示组未匹配比例32.46%，全部预测中为23.57%。提示只提供试听优先级，并不确定错误：提示组大多数仍能匹配。它无法覆盖全部错误，不能称为高精度错误检测。

产品据此增加模型初稿轮廓叠加、原始起止时间提示、逐音符导航及原音播放位置线，帮助使用者对照并修改结束时间。是否减少人工校对时间仍需真实使用者计时验证。

## 参数校准结果（没有提升）

将已经观察过的12段明确作为校准集，对frame threshold的0.15、0.20、0.25、0.30、0.35进行比较。固定起音阈值0.5，选择目标为校准集结束时间F1最大，且起音F1不能比默认下降超过0.01。

校准结果选择默认0.30，其他候选没有达到更好的选择目标。因此没有修改产品默认值，也没有宣称算法提升。

另用随机种子20261011从其余数据中预先固定12段，在选择锁定后才运行。新样本与本项目的校准集不重叠，但不证明与Basic Pitch原始训练集不重叠。

| 项目 | 后续12段验证 |
| --- | --- |
| 音高与起音F1宏平均 | 0.7611 |
| 音高、起音与结束时间F1宏平均 | 0.5722 |
| 选择的frame threshold | 0.30（默认） |

该轮展示默认参数的后续表现，不是性能改进证明；没有比较其他先进模型，也不满足算法模型创新赛题的高分实验要求。

## 软件与测试

27项后端/数据/评测测试通过；浏览器完整工作流测试通过。另用固定诊断样本的第一段真实吉他录音进行浏览器走查，生成140个音符，验证初稿叠加、导航、结束时间修改、MIDI下载与项目删除，无JavaScript异常。自动化走查不是用户试用或用户反馈。

基础模型为Spotify Basic Pitch 0.4.0，未训练新模型；自研范围为网页与服务端的转谱校对流程、记录和验证工具。开发采用AI辅助，参赛者仍需亲自理解、试用、验证并如实说明自己的贡献。
